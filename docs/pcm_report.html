The film drop dominates, and it is the term pcM knows least well — a Dittus–Boelter correlation evaluated at Re = 4755, which is transitional and below the range where that correlation is reliable. Replacing it with a NekRS solution is the single highest-value remaining improvement.

Principal open question for the supervisor

Did pcL model a graphite reflector? A gap of this size in a core this small is the signature of a reflector. pcM built a bare core because the specification stated "single zone, vacuum boundary conditions". If pcL included a reflector, the discrepancy is a specification ambiguity to resolve, not a code disagreement to investigate.

07

Limitations

Stated per the verification hierarchy: software verification and numerical convergence are established; one physics check passes; cross-code comparison is the supervisor's; experimental validation has not been attempted and no experimental data exists here.

  • No fluid solution. NekRS has not run. The coolant is represented by an imposed heat-transfer coefficient and a linear bulk temperature rise.
  • The film coefficient is the dominant uncertainty — 63% of the temperature rise, from a correlation used outside its reliable Reynolds range.
  • Average pin, not hot channel. Peak/average is 2.2544.
  • Thermal properties are assumptions, not specification values: kfuel, kclad, h, and the coolant rise are all documented pcM choices.
  • Library deviation. The coupled production run used ENDF/B-VII.1, not the specified VIII.0; the measured offset is +73 pcm.
  • Bare core. No reflector was modelled, per the specification as written.
