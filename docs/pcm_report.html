02

Scope, objectives and methodology

Objective

Produce an independently reproducible TRIGA Mark I reference calculation using the Cardinal ecosystem, to serve as a cross-code reference against a parallel calculation (“pcL”) performed in GeN-Foam and OFFBEAT. The two calculations were produced without reference to one another; only the scientific problem definition is shared. pcM's results were frozen under git tag pcm-independent-v1 before any pcL material was consulted.

Scope

In scope: steady-state eigenvalue neutronics for a 2-D unit cell and a 3-D bare core; coupled neutronics–conduction for a single pin; standalone coolant CFD.

Out of scope, and not attempted: the +0.5 $ reactivity transient (the project workflow specifies a steady-state production run and defines no transient phase); burnup; control-rod worth; experimental comparison.

Model reduction. The pin-level coupled model is a unit cell, not a full core. This was forced by the original 8 GiB development machine and retained after the move to a 32 GiB host so the coupled result stays comparable to the frozen baseline. It means all coupled temperatures describe an average pin; pcM's own bare-core peaking factor of 2.2544 implies a hot channel is materially hotter.

Methodology

Thermal scattering S(α,β) for c_H_in_ZrH and c_Zr_in_ZrH is applied throughout. Without it the bound-hydrogen physics that defines a TRIGA is absent; §4 demonstrates it is present.

Two defects found in this run

1 · The minimum temperature is below the inlet. 291.52 K in a domain whose only thermal boundary conditions are a 293 K inlet and a heated wall. With no heat sink this cannot be physical; it is an undershoot from the high-pass filter stabilisation and it does not decay.

2 · Three of the four figures are unreadable — they plot axes spanning ±0.04 cm for a channel that is ±2.1 cm wide and 60 cm tall. The simulation data is not at fault: the field files are intact (1 474 560 points, fields UPT, t* = 29.338). Only fluid0.f00000 carries mesh coordinates — every later snapshot is fields-only — so the plotting script read geometry from a file that has none. The fix is in post-processing, not in the solve.

What it would take to converge

Bulk outlet temperature is rising at roughly 0.018 in T* per time unit and energy closure is still climbing steeply. Reaching a defensible steady state needs on the order of five flow-throughs rather than 1.17:

The filter-induced undershoot should be resolved before committing five hours of GPU time, since it indicates the scalar stabilisation is too aggressive and a longer run would inherit the same artifact.

Comparison with pcL

Provenance and scope of this section

pcM's governing instructions assign the pcL comparison to the supervisor. This section is provided at explicit request and is pcM's input to a comparison, not a verdict.

The pcL figures below were not retrieved from a repository. The shared benchmark repository (triga-markI-benchmark, last pushed 2026-09-11) has genfoam/ and results/ containing only .gitkeep placeholders. The values are those supplied in the project handoff message and carry no stated uncertainty except on k-infinity, no model description, and no independent verification. They should be confirmed against pcL's actual output before any conclusion rests on them.

The two calculations are not methodologically equivalent

Before comparing numbers it matters that the codes solve different equations:

pcM (Cardinal)pcL (GeN-Foam / OFFBEAT)
Neutron transportMonte Carlo, continuous energyDeterministic, multigroup diffusion / SP3
Energy treatmentContinuous, full spectrum2 groups, 0.625 eV cutoff
Thermal-fluidSpectral-element LESFinite-volume RANS / porous medium
Fuel performanceNot modelledOFFBEAT
Solution errorStatistical, quantified (±pcm)Discretisation + method, not quantified here
A second candidate explanation for the k-effective gap

pcM's bare core leaks 20.1% of its neutrons. Few-group diffusion theory is least accurate exactly there — strong leakage, steep flux gradients, a small core and a large bound-hydrogen scattering effect. A diffusion solution would be expected to over-predict k in such a configuration, which is the direction of the observed difference.

This compounds with the reflector question rather than replacing it. It is also relevant that pcM never generated the 2-group MGXS the workflow intended it to supply (Phase 6, not run), so pcL's group constants were produced by some other route. Comparing a continuous-energy Monte Carlo k against a 2-group diffusion k computed from independently generated cross sections is not a like-for-like comparison.

Verification status

This work is verified, not validated

Verification asks whether the equations are solved correctly. Validation asks whether the equations describe reality, and is establishable only against experimental data. No experimental data was used anywhere in this work, so no part of it is validated, and agreement between two codes is not a substitute — two codes can agree and both be wrong, particularly when they share a specification, a nuclear data library, or an erroneous assumption.

09

Limitations

Stated per the verification hierarchy: software verification and numerical convergence are established; one physics check passes; cross-code comparison is the supervisor's; experimental validation has not been attempted and no experimental data exists here.

  • The CFD thermal field is not converged. 34.6% energy closure after 1.17 flow-throughs. Coolant temperatures are lower bounds.
  • The CFD shows an unphysical minimum temperature of 291.52 K against a 293 K inlet with no heat sink — a filter-stabilisation artifact that does not decay.
  • Conduction still uses an imposed film coefficient. NekRS ran standalone; it is not yet coupled back, so §3 temperatures still rest on the Dittus-Boelter correlation.
  • No mesh or polynomial-order independence study was performed for the CFD.
  • The film coefficient is the dominant uncertainty — 63% of the temperature rise, from a correlation used outside its reliable Reynolds range.
  • Average pin, not hot channel. Peak/average is 2.2544.
  • Thermal properties are assumptions, not specification values: kfuel, kclad, h, and the coolant rise are all documented pcM choices.
  • Library deviation. The coupled production run used ENDF/B-VII.1, not the specified VIII.0; the measured offset is +73 pcm.
  • Bare core. No reflector was modelled, per the specification as written.
