# Results

Curated, small result files. Large outputs (OpenMC statepoints, Exodus
fields, NekRS checkpoints) are regenerated by the scripts and not committed.

## `cardinal/` — Monte Carlo / multiphysics

| File | Contents |
|---|---|
| `openmc_unitcell.csv` | k-infinity, every configuration and seed (smoke, baseline, production) |
| `openmc_core.csv` | k-effective, heterogeneous bare core |
| `openmc_core_homog.csv` | k-effective, homogenised core, three hydrogen kernels |
| `pin_power_core.csv`, `power_*_core.csv` | Pin powers, radial/axial profiles, power summary |
| `fuel_temperature_coefficient.csv` | Fuel temperature sweep, unit cell (k∞) |
| `core_temperature_coefficient.csv` | Fuel temperature sweep, bare core (k_eff) |
| `leakage_feedback.csv` | Lattice vs core coefficient by band, with the leakage term |
| `coupled_production_vii1.csv` | OpenMC–MOOSE coupled run, MOOSE postprocessors per Picard iteration |
| `coupled_production_openmc_vii1.csv` | Same run, OpenMC sub-app history |
| `coupled_smoke.csv` | Coupled smoke run |
| `thermal_profiles.csv`, `.json` | Axial and radial temperature profiles from the coupled solution |
| `nekrs_convergence.csv`, `nekrs_gpu_diagnostic.csv` | NekRS CFD history and GPU diagnostic (not used as results) |
| `summary_*.csv` | One-line summaries: conservation checks, neutronics, coupled run |
| `entropy/` | Shannon entropy per run (source convergence) |

Every OpenMC row records seed, particles, batches, OpenMC version, nuclear-data
checksum, platform, wall clock and timestamp.
